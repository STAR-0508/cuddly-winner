### DeepSeek 正式开放"全家桶"API
- 2026-11-13，DeepSeek 更新 API 文档，将 DeepSeek App / 网页端内的**联网搜索、深度思考搜索、文件上传、链接阅读、语音交互、安全管控**等能力全部开放为独立 API 接口，支持各模块独立调用、分别计费。官方宣称开发者可"1:1 复刻 DeepSeek App"。[官方 API 文档](https://api-docs.deepseek.com/zh-cn/updates/) [腾讯云开发者社区](https://developer.cloud.tencent.com/article/2784147)
- **为什么重要**：这是国产大模型厂商首次将完整应用能力 API 化，大幅降低了 AI Agent 与应用层开发者的集成门槛，对中文 AI 开发生态具有结构性意义。

### Google 发布 Gemini 4 Hydrogen：便宜档跑分反超旗舰
- 2026-11-12，Google 正式发布 Gemini 4 Hydrogen，接替上一代 Flash 成为效率执行层。与 Gemini 3.8 Flash 相比，**同等设置下任务完成速度提升 2.5 倍**，Terminal-Bench 4.1 得分从 18.2% 跃升至 57%，部分编程指标甚至超过旗舰 Carbon 模型。同时推出 Antigravity Orchestrator 自动路由工具，可在 Carbon 与 Hydrogen 间切换以省 24% 额度、提速 19%。[华尔街见闻](http://m.toutiao.com/group/7707398988319703594/) [36氪](https://36kr.com/p/4068060515997320)
- **为什么重要**：Google 将"效率模型"做成了系列主力，标志着大模型竞争已从"旗舰参数"转向"综合性价比 + 智能体任务适配"。免费用户也能体验，普惠性显著提升。

### 微软向约 6 万名员工提供自愿买断方案，占全球员工 27%
